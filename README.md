# Blackjack Card Game 🎴

This is a Java-based Blackjack card game developed as part of my Object-Oriented Programming (OOP) assignment.

## 💡 Features
- Object-oriented structure with clear separation of concerns
- Player vs Dealer gameplay logic
- Uses Java classes like `Player`, `Game`, and `GroupOfCards`
- Console-based interaction

## 🛠️ Technologies
- Java
- OOP Concepts: Inheritance, Encapsulation, Polymorphism, Abstraction

## 📁 Files
- `Game.java`: Main game logic
- `Player.java`: Player details and actions
- `GroupOfCards.java`: Card management
- `Main.java`: Entry point to run the game

## 🎓 Educational Purpose
This project was built to practice and demonstrate understanding of Java OOP principles.
